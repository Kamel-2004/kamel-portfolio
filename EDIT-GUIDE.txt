EDIT GUIDE: Kamel Khoudiery portfolio
============================================================

HOW TO UPDATE THE LIVE SITE
1. Edit the file on your computer (any text editor, or Notepad).
2. In your GitHub repo, open the file's folder, click Add file > Upload files, drop the changed file, Commit changes.
3. Wait 1 to 5 minutes. For images, just upload them into the right folder with the exact name below.

Line numbers below were correct when this guide was made. If you add or delete lines, they shift; use the quoted text to search (Ctrl+F).

FOLDERS
  index.html    page structure and most text
  css/style.css colours, sizes, layout
  js/work.js    YOUR PROJECTS (edit this one most often)
  js/main.js    animations and behaviour (rarely touched)
                (the header's see-through effect is a small script at the very
                end of index.html, lines 83 to 86; do not delete it)
  fonts/        font files (do not touch)
  photos/       your portrait and background
  photos/work/  one cover image per project
